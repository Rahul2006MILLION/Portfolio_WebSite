# My Portfolio Website

An ultra-premium, cinematic interactive developer portfolio for Rahul Jain.

## Tech Stack

- Next.js
- TypeScript
- React
- Tailwind CSS
- Three.js
- React Three Fiber
- React Three Drei
- GSAP + ScrollTrigger
- Lenis
- Motion

## Planned Experience

- Cinematic portrait-based WebGL hero
- Interactive projects and case studies
- Live GitHub statistics
- LeetCode streaks and problem-solving statistics
- DSA pattern visualizations
- Professional timeline and LinkedIn integration

## Development

Run `npm install` and then `npm run dev`.
